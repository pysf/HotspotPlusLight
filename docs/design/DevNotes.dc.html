Hard parts in plain CSS

1. Stacked cards on phone

Each <td> carries data-label="Plan". Under 700 px, tr becomes a grid and td::before prints the label. The thead is hidden by clipping, not display:none, so screen readers keep the column names. Tables with a checkbox use the default 3-column card, without one use .table-plain.

2. One markup, two widths

The boards use container queries (@container hp (max-width: 699px)) so 1280 and 390 can sit side by side. In production you can keep them (all current browsers) or replace with @media (max-width: 699px), same numbers: 999 px = icon rail, 699 px = phone.

3. Meter width without inline style

Width comes from classes pct-0 … pct-100 in steps of 5. The server rounds the real percent to the nearest 5 and puts the exact value in aria-valuenow and in the text beside it. Colour class by rule: under 80% normal, 80–99% .meter-warn, 100% .meter-bad.

4. Charts

Draw them on the server as inline SVG. Geometry goes in attributes (d, cx), looks go in classes (.ch-line, .ch-bar). Bars are one <path> of vertical strokes with round caps: short, and one element per series. Give every chart role="img" and an aria-label that says the main fact in words.

5. Light / dark

Set data-theme on <html>. Without it the OS decides. A tiny external theme.js in <head> (not inline) reads localStorage before paint to avoid a flash. The theme button swaps its own icon with CSS (.ic-sun / .ic-moon).

6. Sheet, dialog, menu

Prefer native <dialog> with showModal(): free focus trap, Esc, and ::backdrop for the scrim. Style dialog.sheet and dialog.dialog with the same classes. Row menus: a popover or ten lines of JS (arrow keys, Esc, return focus to the button). On phone the sheet becomes a nearly full-height bottom sheet.

7. Blur

backdrop-filter is only polish. Add @supports not (backdrop-filter: blur(1px)) and set --c-glass to the solid surface colour.

8. Phone “More”

The 5th tab opens a small list (Plans, Usage, Router, Settings). It can be a plain <details> or a menu. The tab shows as current when any of those pages is open.

htmx notes

  • Dashboard refresh: hx-get="/dashboard/live" hx-trigger="every 10s [!document.hidden]" hx-swap="innerHTML settle:300ms" on the tiles, attention list, router card and charts (one region each). Tiles have a min-height, numbers use tabular-nums, charts keep a fixed viewBox: nothing resizes, so nothing jumps.
  • Swapped content gets .swap-in (55% to 100% opacity, 0.4 s). Do not animate unchanged values. Do not put aria-live on the refreshed regions.
  • Skip the swap while a menu or dialog is open (hx-trigger filter on a body class).
  • Same pattern for Online now (10 s) and the “Updated 4 s ago” text (tiny JS timer).
  • Toast: send HX-Trigger: {"toast":{"text":"Business details saved"}}. Small JS appends .toast with role="status" and removes it after 4 s. Errors use .toast-bad with role="alert" and stay until closed.
  • Field errors: return the form fragment with aria-invalid="true" and .field-err; use hx-swap="outerHTML" on the form so focus can move to the first error.
  • Bulk actions: checkboxes inside the table form; .bulk appears when one or more are checked. Delete asks in a dialog first.
  • Usage range: the 7 / 30 / 90 buttons use hx-get="/usage?days=30" with hx-target on the chart and list; keep aria-checked in sync.

Accessibility checklist

  • Text contrast 4.5:1 or more in both themes (checked on every token pair). Borders on inputs 3:1 (--c-input-line).
  • Focus: :focus-visible 3 px outline in --c-focus, offset 2 px. Never remove it.
  • Status = icon + word + colour. Online = filled dot vs hollow ring, plus the word.
  • Delete-blocked button uses aria-disabled="true" (stays focusable) and aria-describedby pointing at the visible reason.
  • Reduced motion switches off all animation. Touch targets 44 px under 700 px.
  • No sideways scroll from 360 px: all grids are minmax(0, 1fr), long values use overflow-wrap:anywhere.

Icons

One inline SVG sprite in the base layout (24 px grid, stroke 1.75, stroke="currentColor"). Use <svg class="ic" aria-hidden="true"><use href="#i-name"/></svg>. Icon-only buttons need aria-label. The sprite on these boards is repeated per file only because each board is separate.
