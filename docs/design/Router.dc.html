Setup script

Paste this into the router’s New Terminal. It adds your RADIUS server and turns it on for the hotspot.

# HotspotPlus Lite · RADIUS setup
/radius add service=hotspot address=192.168.88.10 secret="k8Qm-2Tz-91xd" authentication-port=1812 accounting-port=1813 timeout=3s
/ip hotspot profile set [find default=yes] use-radius=yes radius-accounting=yes radius-interim-update=1m login-by=http-chap,http-pap
/radius incoming set accept=yes port=3799

How to upload the pages

  1. Download the pages you want, or all eight.
  2. In WinBox, open Files and drag them into the hotspot folder.
  3. Open IP › Hotspot › Server Profiles and set HTML Directory to hotspot.
  4. Join the Wi-Fi on a phone and check the sign-in page.
