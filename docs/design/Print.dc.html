Page

  • A4, portrait, 10 mm inside margin. Set the browser margin to None.
  • 3 columns × 6 rows = 18 vouchers per page. Each card is 63 × 42 mm.
  • Business name is the page title. It also sits small on every card, so a cut-out card still says whose Wi-Fi it is.
  • More than 18 vouchers: a new page starts, with the same header and “Page 2 of 3”.

Type and ink

  • Black on white only, even if the app is in dark mode.
  • Username and password: mono, bold, 13 pt, so 0 / O and l / 1 are easy to tell apart. Passwords skip look-alike letters.
  • Labels 7.5 pt capitals. Help text 8 pt, one sentence.
  • Dashed 0.25 mm cut lines. No colour, no shadows, no icons.

Hidden when printing

  • Side bar, top bar, tab bar, and the Back / Print buttons (class no-print).
  • @page { size: A4; margin: 0 } and break-inside: avoid on each card.
