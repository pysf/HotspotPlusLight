    Dashboard

    What the Dashboard shows: who is online, traffic, failed logins, the Router link card, members that need attention and 3 charts.

    Open the Dashboard

    After you log in, the Dashboard is the first page you see. It is also the first item in the sidebar. The brand name in the top bar takes you back to it.

    The whole page refreshes by itself every 10 seconds, so you can leave it open. All times and days follow the Time zone setting on the Settings page. A new install has no data yet, so the lists and charts show a short message instead.

    The four tiles

    TileWhat it shows
    Online nowThe open sessions that the router still reports. This is the same number as on the Online now page, so one member on 2 devices counts twice.
    Peak todayThe most sessions online at one moment since midnight.
    Traffic todayDownload plus upload since midnight, so far. The tile compares it with yesterday and with the same weekday last week, as a percent. When the day it is compared with has no traffic, the tile shows no data and no percent.
    Failed logins todayHow many logins failed today, and the most common reason. See How failed logins are counted.

    Router link

    The Router link card shows what the MikroTik router last sent to the server: the time and source address of the last login request, the last accounting packet and the last Disconnect result. It also shows how many packets had a wrong shared secret. The label next to the title says Healthy when a login or accounting packet came in the last 5 minutes, No recent packets when none did, and Wrong secret when a packet had a wrong shared secret.

    The card is kept in memory and is empty after the server restarts. Every row shows never until the router sends something. It used to be on the Router page. The Router page now has only the login page designs and the setup script. If the rows stay empty after a login, see Troubleshooting.

    Needs attention

    This is one card with 2 short lists. Each list shows the full count in its title and at most 5 members. The label next to the card title shows the number of items, or All clear:

    • Expiring in 3 days: active members whose expiry time is in the next 3 days. You may want to renew them. The list uses the same rule as the Expiring soon filter on the Members page.
    • Near the data limit: members who have used 80% or more of their data in the current period. A member whose period has already ended is not listed.

    The three charts

    • Traffic, last 14 days: download plus upload for all members, one bar per day. The Usage page has 7, 30 and 90 day ranges and the top members.
    • Busy hours: for each hour of the day, the average number of people online over the last 14 days. Use it to see when the Wi-Fi is busiest. The current hour counts only for the part that has passed.
    • Active members per day: how many different members used any data on each of the last 14 days. A login with no traffic does not count.

    How failed logins are counted

    A failed login is one refusal that the server sends back to the router, for any reason: wrong user name or password, expired account, no data left, no plan, too many devices and so on. The server adds 1 to a counter for that day and that reason.

    • No personal data. Only the day, the reason code and the count are stored. No user names and no addresses.
    • A retry counts once. The router repeats a request every few seconds when it gets no answer. The server remembers the last 1024 requests for 60 seconds, so it does not count a repeat of the same request again.
    • Not counted: accepted logins, and packets the server does not answer (for example, a packet with a wrong shared secret). The Router link card counts the packets with a wrong shared secret.
    • How long it is kept. The counts are kept as long as the sessions: the Session retention (days) setting (Keep finished sessions (days) on the Settings page), 90 by default. Older counts are deleted with the old sessions. With 0 they are kept forever.
