    Dashboard

    What the admin home page shows: who is online, traffic, failed logins, the router status, members that need attention, and three charts.

    Open the dashboard

    After you log in, the Dashboard is the first page. It is also the first item in the sidebar. The brand name in the top bar takes you back to it.

    The whole page refreshes by itself every 10 seconds, so you can leave it open. All times and days follow the time zone on the Settings page. A new install has no data yet, so the lists and charts show a short text instead.

    The three tiles

    TileWhat it shows
    Online nowThe open sessions that the router still reports. It is the same number as on the Online page, so one member on two devices counts twice. The note shows the peak today: the most sessions online at one moment since midnight.
    Traffic todayDownload plus upload since midnight, so far. It is compared with yesterday and with the same weekday last week, as a percent. When the day it is compared with has no traffic, the tile says no data and shows no percent.
    Failed logins todayHow many logins the server refused today, and the most common reason. See How failed logins are counted.

    Router status

    This panel shows what the router last sent to the server: the time and source address of the last login request, the last accounting packet and the last Disconnect result, and how many packets had a wrong shared secret.

    It lives in memory and starts empty after the server restarts, so every row says never until the router sends something. It used to be on the Router page; the Router page now has only the page designs and the setup script. If the rows stay empty after a login, see Troubleshooting.

    Needs attention

    Two short lists, with the full count in the heading and at most five members shown:

    • Expiring in 3 days: active members whose expiry date is in the next 3 days. They are good people to renew. It is the same rule as the Expiring filter on the Members page.
    • Near the data limit: members who used 80% or more of their data in the current period. A member whose period already ended is not listed.

    The three charts

    • Traffic, last 14 days: download plus upload for all members, one bar per day. The Usage page has longer ranges and the top members.
    • Busy hours: for each hour of the day, the average number of people online over the last 14 days. Use it to see when the Wi-Fi is busiest. The hour that is running now counts only for the part that has passed.
    • Active members per day: how many different members used any data on each of the last 14 days. A login without traffic does not count.

    How failed logins are counted

    A failed login is one refusal that the server sends back to the router, for any reason: wrong user name or password, expired, out of data, no plan, too many devices, and so on. The server adds 1 to a counter for that day and that reason.

    • No personal data. Only the day, the reason code and the count are stored. No user names and no addresses.
    • A retry counts once. The router repeats a request every few seconds when it does not get the answer. The server remembers the last 1024 requests for 60 seconds, so a repeat of the same request is not counted again.
    • Not counted: accepted logins, and packets the server does not answer, such as a wrong shared secret. Wrong secrets show in the Router status panel.
    • How long it is kept. The counts are kept as long as the sessions: the Session retention (days) setting, 90 by default. Older counts are deleted with the old sessions. With 0 they are kept forever.
