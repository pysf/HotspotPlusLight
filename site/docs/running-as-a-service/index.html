    Running as a service

    Run HotspotPlus Lite in the background and start it at boot, on Linux, Windows or macOS.

    Linux (systemd)

    The program can install itself as a systemd service. Go to the folder with hotspotpluslight and run it with sudo:

    sudo ./hotspotpluslight service install
sudo ./hotspotpluslight service start

    service install does this:

    • It never follows symbolic links: it stops if hsp.env, the program file or anything in the data folder is a link.
    • It creates the system user hotspotpluslight (no login) if the user does not exist. If useradd is missing, it tells you how to create the user by hand.
    • It creates the folder /var/lib/hotspotpluslight. To use another folder, add --dir /opt/hsp. The folder belongs to the service user (mode 0750). The install refuses a folder under /home, /root or /run/user, because the unit hides them, and it refuses a folder that is a symbolic link. Missing parent folders are created owned by root.
    • It copies the program to hotspotpluslight in that folder. The service user owns the file, so Update now can replace it.
    • If the env file hsp.env does not exist yet, it creates the file with a new HSP_SECRET_KEY, and with HSP_DATA_DIR set to the data subfolder. Only the service user can read it. An existing hsp.env is kept as it is, but its mode is set to 0600.
    • It writes /etc/systemd/system/hotspotpluslight.service, runs systemctl daemon-reload and systemctl enable.

    The unit restarts the program after any exit (Restart=always, after 2 seconds). This includes the restart after an update (exit code 75). The logs and the first-start block are in the journal:

    journalctl -u hotspotpluslight -f

    Back up the folder: it holds the database, hsp.env and the key. Stop and remove the service with the commands below. Your data folder and the user are kept.

    sudo ./hotspotpluslight service stop
sudo ./hotspotpluslight service uninstall

    All the default ports are above 1024, so the service needs no extra privileges. If you choose a port below 1024, add AmbientCapabilities=CAP_NET_BIND_SERVICE to the [Service] part of the unit file, then run sudo systemctl daemon-reload and restart the service.

    The unit file looks like this (with the default folder):

    [Unit]
Description=HotspotPlusLight
After=network-online.target
Wants=network-online.target

[Service]
Type=simple
User=hotspotpluslight
WorkingDirectory=/var/lib/hotspotpluslight
ExecStart=/var/lib/hotspotpluslight/hotspotpluslight --env-file /var/lib/hotspotpluslight/hsp.env serve
Restart=always
RestartSec=2
NoNewPrivileges=yes
ProtectSystem=full
ReadWritePaths=/var/lib/hotspotpluslight
ProtectHome=yes
PrivateTmp=yes
LimitNOFILE=65536
StandardOutput=journal

[Install]
WantedBy=multi-user.target

    systemctl stop sends SIGTERM. The server then stops taking new requests and lets the accounting requests (usage updates from the router) that are already in progress finish. Then it closes the database.

    If you forget the admin password, run the reset as the service user, so that the database files keep their owner:

    sudo -u hotspotpluslight /var/lib/hotspotpluslight/hotspotpluslight admin set-password --env-file /var/lib/hotspotpluslight/hsp.env

    Windows service

    The program can install itself as a Windows service. Open PowerShell as Administrator, go to the folder with hotspotpluslight.exe and run:

    cd C:\hotspotpluslight
.\hotspotpluslight.exe service install
.\hotspotpluslight.exe service start

    service install does this:

    • It creates the folder C:\ProgramData\HotspotPlusLight. To use another folder, add --dir D:\hsp.
    • It lets only SYSTEM and Administrators open that folder, because the folder holds the secret key.
    • If the env file hsp.env does not exist yet, it creates the file with a new HSP_SECRET_KEY, and with HSP_DATA_DIR set to the data subfolder.
    • It registers the service HotspotPlusLight (display name "HotspotPlus Lite"). The service starts with Windows and runs serve --env-file with that file.
    • It sets the service to restart after a failure, after 5, 15 and 60 seconds.

    The logs and the first-start block are in hsp.log in that folder:

    type C:\ProgramData\HotspotPlusLight\hsp.log

    To stop and remove the service, run the commands below. Your data is kept.

    .\hotspotpluslight.exe service stop
.\hotspotpluslight.exe service uninstall

    Do not move hotspotpluslight.exe after the install, because the service points to it. To reset the admin password:

    .\hotspotpluslight.exe admin set-password --env-file C:\ProgramData\HotspotPlusLight\hsp.env

    Allow the ports in the Windows firewall. Run this in PowerShell as Administrator:

    netsh advfirewall firewall add rule name="HotspotPlus Lite admin" dir=in action=allow protocol=TCP localport=8081
netsh advfirewall firewall add rule name="HotspotPlus Lite RADIUS" dir=in action=allow protocol=UDP localport=1812-1813
    Keep a copy of hsp.env

    It holds the secret key. Without the key, the stored member passwords cannot be read. See Backup and upgrade.

    macOS (launchd)

    The service commands work only on Windows and Linux. On macOS, use launchd. Put variables such as HSP_DATA_DIR in the env file /usr/local/etc/hotspotpluslight.env (readable only by root). Then create /Library/LaunchDaemons/local.hotspotpluslight.plist:

    <?xml version="1.0" encoding="UTF-8"?>
<plist version="1.0">
<dict>
  <key>Label</key><string>local.hotspotpluslight</string>
  <key>ProgramArguments</key>
  <array>
    <string>/usr/local/bin/hotspotpluslight</string>
    <string>--env-file</string>
    <string>/usr/local/etc/hotspotpluslight.env</string>
    <string>serve</string>
  </array>
  <key>RunAtLoad</key><true/>
  <key>KeepAlive</key><true/>
  <key>StandardOutPath</key><string>/var/log/hotspotpluslight.log</string>
  <key>StandardErrorPath</key><string>/var/log/hotspotpluslight.log</string>
</dict>
</plist>

    launchd starts the program in the / folder. The data folder defaults to the relative path data, so the database would go to /data, which is read-only. Set the data folder in the env file and create it:

    echo 'HSP_DATA_DIR=/usr/local/var/hotspotpluslight' | sudo tee -a /usr/local/etc/hotspotpluslight.env >/dev/null
sudo mkdir -p /usr/local/var/hotspotpluslight
    sudo launchctl bootstrap system /Library/LaunchDaemons/local.hotspotpluslight.plist
sudo launchctl bootout system /Library/LaunchDaemons/local.hotspotpluslight.plist

    The first command starts the service. The second command stops it. The project does not test launchd, so use this setup as a starting point.

    Check that it runs

    On the server, curl http://127.0.0.1:8081/healthz prints ok. In a browser, http://SERVER-IP:8081/admin shows the admin login page. Then continue with First login.
