    Installation

    Download the program for your system, start it once and open the admin panel. Building it from source is also easy.

    Download

    Every release has 9 files. Each file holds the program, README.md and LICENSE. The file names have no version number, so these links always give you the newest release.

    SystemBuildFile
    Linuxx86 64-bithotspotpluslight-linux-amd64.tar.gz
    Linuxx86 32-bithotspotpluslight-linux-386.tar.gz
    LinuxARM 64-bithotspotpluslight-linux-arm64.tar.gz
    LinuxARM 32-bit (ARMv7, Raspberry Pi 2 and newer)hotspotpluslight-linux-arm.tar.gz
    Windowsx86 64-bithotspotpluslight-windows-amd64.zip
    Windowsx86 32-bithotspotpluslight-windows-386.zip
    WindowsARM 64-bithotspotpluslight-windows-arm64.zip
    macOSIntelhotspotpluslight-darwin-amd64.tar.gz
    macOSApple siliconhotspotpluslight-darwin-arm64.tar.gz

    The checksums are in SHA256SUMS. To check a file, run sha256sum FILE on Linux, shasum -a 256 FILE on macOS or Get-FileHash -Algorithm SHA256 FILE in PowerShell. Then compare the result with that list.

    There is no Windows 32-bit ARM build and no 32-bit macOS build, because Go does not support them. The 32-bit ARM Linux build needs ARMv7, so it does not run on the Raspberry Pi Zero or Pi 1.

    Linux

    Download, unpack and install the program:

    curl -LO https://github.com/pysf/HotspotPlusLight/releases/latest/download/hotspotpluslight-linux-amd64.tar.gz
tar -xzf hotspotpluslight-linux-amd64.tar.gz
sudo install -m 755 hotspotpluslight /usr/local/bin/
hotspotpluslight version

    Start the server from the same folder. At the first start, the server creates the secret key and the database:

    hotspotpluslight serve

    By default, the database and the secret key (hsp.key) go in a folder called data, in the folder where you run the command. Back up that data folder: it holds both hsp.db and hsp.key.

    Set HSP_DATA_DIR to use a different data folder. Set HSP_SECRET_KEY if you want to manage the key yourself, so the server does not create one. The server creates a key only for a new data folder. If hsp.db exists and the key is missing, the server does not start. To start the server at boot, see Run as a service.

    macOS

    Use darwin-arm64 on Apple silicon or darwin-amd64 on an Intel Mac:

    curl -LO https://github.com/pysf/HotspotPlusLight/releases/latest/download/hotspotpluslight-darwin-arm64.tar.gz
tar -xzf hotspotpluslight-darwin-arm64.tar.gz
./hotspotpluslight version

    Then start the server as shown for Linux. If macOS blocks a file you downloaded in a browser, remove the quarantine mark with xattr -d com.apple.quarantine hotspotpluslight.

    Windows

    Open PowerShell, then download and unpack the zip:

    curl.exe -LO https://github.com/pysf/HotspotPlusLight/releases/latest/download/hotspotpluslight-windows-amd64.zip
Expand-Archive hotspotpluslight-windows-amd64.zip -DestinationPath C:\hotspotpluslight
cd C:\hotspotpluslight
.\hotspotpluslight.exe version

    To try it in the PowerShell window, start it:

    .\hotspotpluslight.exe serve

    For daily use, install the Windows service instead. The service install creates the env file and the secret key for you. See Run as a service.

    The first start

    On the first start, the server creates the database and the admin account, and prints this block. The log lines go to stderr and the block goes to stdout. This is the real output:

    time=2026-11-04T17:44:47.540+01:00 level=INFO msg="migrations applied" count=4
=== HotspotPlus Lite first start ===
Log in with username: admin  password: admin
You will be asked to set a new password right after you log in.
Forgot it later? Run: hotspotpluslight admin set-password
====================================
time=2026-11-04T17:44:47.593+01:00 level=INFO msg="admin account created with the default password; it must be changed at first login"
time=2026-11-04T17:44:47.594+01:00 level=INFO msg=listening admin=[::]:8080 radius_auth=[::]:1812 radius_acct=[::]:1813

    When you start the server from a terminal, it prints Admin panel: http://localhost:8080/admin and opens that page in your browser by itself. Set HSP_OPEN_BROWSER=0 to stop that. From another computer, open http://SERVER-IP:8080/admin in a browser. SERVER-IP is the address of the computer that runs the server. The /healthz address answers ok without a login, so monitoring tools can use it.

    Build from source

    You need Go 1.26 (see go.mod) and make. The build needs no cgo and no Node.js step.

    git clone https://github.com/pysf/HotspotPlusLight.git
cd HotspotPlusLight
make build

    make build writes bin/hotspotpluslight. For a 64-bit Windows program, use make build-windows, which writes bin/hotspotpluslight.exe. make run builds and starts the server with its data in ./data. At the first start, the server creates the key in data/hsp.key.

    Ports

    The MikroTik router talks to the server with RADIUS (the protocol the router uses to ask the server about each login).

    PortDirectionUsed for
    TCP 8080to the server, from your computerThe admin panel and /healthz (plain HTTP).
    UDP 1812to the server, from the routerRADIUS login requests.
    UDP 1813to the server, from the routerRADIUS accounting (usage updates the router sends during a session).
    UDP 3799to the router, from the serverDisconnect requests (the port is a setting).

    You can change the addresses and ports of the server on the Settings page (restart required). The environment variables HSP_ADMIN_ADDR, HSP_RADIUS_AUTH_ADDR and HSP_RADIUS_ACCT_ADDR are used only at the first start. After that, the server uses the Settings page. See Configuration. For the firewall rules, see Router setup.
