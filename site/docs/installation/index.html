    Installation

    Download the program for your system, start it once, and open the admin panel. Building from source is also easy.

    Download

    Every release has nine files. Each holds the program, README.md and LICENSE. The file names have no version, so these links always give the newest release.

    SystemBuildFile
    Linuxx86 64-bithotspotpluslight-linux-amd64.tar.gz
    Linuxx86 32-bithotspotpluslight-linux-386.tar.gz
    LinuxARM 64-bithotspotpluslight-linux-arm64.tar.gz
    LinuxARM 32-bit (ARMv7, Raspberry Pi 2 and newer)hotspotpluslight-linux-arm.tar.gz
    Windowsx86 64-bithotspotpluslight-windows-amd64.zip
    Windowsx86 32-bithotspotpluslight-windows-386.zip
    WindowsARM 64-bithotspotpluslight-windows-arm64.zip
    macOSIntelhotspotpluslight-darwin-amd64.tar.gz
    macOSApple siliconhotspotpluslight-darwin-arm64.tar.gz

    The checksums are in SHA256SUMS. To check a file: sha256sum FILE on Linux, shasum -a 256 FILE on macOS, or Get-FileHash -Algorithm SHA256 FILE in PowerShell, then compare the result with that list.

    There is no Windows 32-bit ARM build and no 32-bit macOS build, because Go does not support them. The 32-bit ARM Linux build needs ARMv7, so it does not run on the Raspberry Pi Zero or Pi 1.

    Linux

    Download, unpack and install the program:

    curl -LO https://github.com/pysf/HotspotPlusLight/releases/latest/download/hotspotpluslight-linux-amd64.tar.gz
tar -xzf hotspotpluslight-linux-amd64.tar.gz
sudo install -m 755 hotspotpluslight /usr/local/bin/
hotspotpluslight version

    Make a settings file with a new secret key. The key encrypts the member passwords, so keep a copy (see Backup and upgrade):

    printf 'HSP_SECRET_KEY=%s\n' "$(hotspotpluslight gen-key)" > hsp.env
chmod 600 hsp.env

    Start the server from the same folder:

    hotspotpluslight --env-file hsp.env serve

    By default the database goes in a folder called data next to where you run the command. Set HSP_DATA_DIR to put it somewhere else. To start at boot, see Running as a service.

    macOS

    Use darwin-arm64 on Apple silicon or darwin-amd64 on an Intel Mac:

    curl -LO https://github.com/pysf/HotspotPlusLight/releases/latest/download/hotspotpluslight-darwin-arm64.tar.gz
tar -xzf hotspotpluslight-darwin-arm64.tar.gz
./hotspotpluslight version

    Then create hsp.env and start the server as shown for Linux. If macOS blocks a file you downloaded in a browser, remove the quarantine mark with xattr -d com.apple.quarantine hotspotpluslight.

    Windows

    Open PowerShell, then download and unpack the zip:

    curl.exe -LO https://github.com/pysf/HotspotPlusLight/releases/latest/download/hotspotpluslight-windows-amd64.zip
Expand-Archive hotspotpluslight-windows-amd64.zip -DestinationPath C:\hotspotpluslight
cd C:\hotspotpluslight
.\hotspotpluslight.exe version

    To try it in the window, set a key and start it:

    $env:HSP_SECRET_KEY = (.\hotspotpluslight.exe gen-key)
.\hotspotpluslight.exe serve

    For daily use, install the Windows service instead. It makes the settings file and the key for you. See Running as a service.

    The first start

    On the first start the server creates the database, creates the admin account and prints this block. The log lines go to stderr and the block goes to stdout. This is the real output:

    time=2026-11-04T17:44:47.540+01:00 level=INFO msg="migrations applied" count=4
=== HotspotPlus Lite first start ===
Log in with username: admin  password: admin
You will be asked to set a new password right after you log in.
Forgot it later? Run: hotspotpluslight admin set-password
====================================
time=2026-11-04T17:44:47.593+01:00 level=INFO msg="admin account created with the default password; it must be changed at first login"
time=2026-11-04T17:44:47.594+01:00 level=INFO msg=listening admin=[::]:8081 radius_auth=[::]:1812 radius_acct=[::]:1813

    Open http://SERVER-IP:8081/admin in a browser. SERVER-IP is the address of the computer that runs the server. The address /healthz answers ok without a login, for monitors.

    Build from source

    You need Go 1.26 (see go.mod) and make. The build has no cgo and no Node step.

    git clone https://github.com/pysf/HotspotPlusLight.git
cd HotspotPlusLight
make build

    make build writes bin/hotspotpluslight. For a 64-bit Windows program use make build-windows, which writes bin/hotspotpluslight.exe. make run builds and starts the server with data in ./data, using a development key kept in the git-ignored file .dev-secret-key.

    Ports

    PortDirectionUsed for
    TCP 8081to the server, from your computerThe admin panel and /healthz (plain HTTP).
    UDP 1812to the server, from the routerRADIUS login requests.
    UDP 1813to the server, from the routerRADIUS accounting.
    UDP 3799to the router, from the serverDisconnect requests (the port is a setting).

    The addresses and ports of the server can be changed with HSP_ADMIN_ADDR, HSP_RADIUS_AUTH_ADDR and HSP_RADIUS_ACCT_ADDR, see Configuration. The firewall rules are on the Router setup page.
