    Hotspot login pages

    The 8 downloadable login page designs, how to edit the heading, subtitle and logo, and how to translate the messages.

    The 8 designs

    The Router page of the admin panel offers 8 downloads. Each is a complete hotspot folder for the router. Seven use one layout with a different color theme. You can open a preview of each one before you download it.

    KeyDesignLook
    mikrotikMikroTik defaultThe pages exactly as RouterOS ships them. Failed logins show the raw code.
    airAirLight grey with Apple blue.
    midnightMidnightGraphite with a blue glow and a faint grid.
    auroraAuroraPastel mesh with a frosted glass card.
    duskDuskViolet-black with a glow from below.
    rippleRippleSage paper with signal rings.
    sunriseSunriseWarm cream with a low sun.
    oceanOceanDeep teal with a white card.

    The zip is named hotspot-KEY.zip and holds the folder hotspot/.

    What is in the folder

    The themed folders contain:

    • login.html, alogin.html, status.html, logout.html, error.html: the pages members see.
    • css/hotspot.css: the layout and the colors of the theme. js/busy.js: an optional spinner and double-submit guard; the pages work without it.
    • redirect.html, rlogin.html, radvert.html, api.json, errors.txt, xml/ and favicon.ico: small helper files the router uses.

    The pages make no requests to other sites and need no web fonts. Nothing on them calls the HotspotPlus Lite server: the router shows the pages by itself.

    Edit the heading, subtitle and logo

    Open login.html in a text editor. Comments in the file show where to change things:

    • Heading: the text of the <h1>, "Welcome" by default.
    • Subtitle: the text of the line below it, with the class sub.
    • Logo: upload your logo to the hotspot folder as img/logo.png, and replace the logo block with <div class="logo"><img src="img/logo.png" alt=""></div>. Delete the block for a text-only page.

    Keep the form as it is: the action, the field names username and password, and the two hidden fields. Then upload the folder to the router again.

    Translate the messages

    When the server rejects a login it sends only a short code. login.html turns the code into text in a block called MESSAGES - translate here:

    $(if error == "INVALID_CREDENTIALS")Wrong username or password.
$(elif error == "INACTIVE_USER")This account is disabled.
$(elif error == "NO_PLAN")No internet plan is assigned to this account.
...
$(elif error == "UNSUPPORTED_AUTH_METHOD")This network only supports PAP login.
$(elif error)$(error)$(endif)

    Change the text after each code. Do not change the codes in capital letters. The last line shows any other message from the router as it is. Also translate:

    • errors.txt: messages for router-side problems. Change the text after the = sign and keep the names on the left.
    • The labels in status.html ("Hi", "Time online", "Time left", "Data left (bytes)", "Continue", "Log out") and the other pages.

    The MikroTik default design shows the raw code, for example OUT_OF_BULK, so use one of the themes if you want readable messages.

    Reason codes

    These are all the codes the server can send:

    CodeDefault textWhen
    INVALID_CREDENTIALSWrong username or password.Unknown user or wrong password.
    INACTIVE_USERThis account is disabled.The member is disabled.
    NO_PLANNo internet plan is assigned to this account.The member has no plan (cannot normally happen).
    PLAN_REMOVEDThis plan has been removed.The plan no longer exists (a safety net).
    EXPIREDThis account has expired.The member's Valid until time has passed.
    NO_ACTIVE_SUBSCRIPTIONYour plan period has ended.The validity period is over and the plan does not renew itself.
    OUT_OF_BULKYour data allowance is used up.No data is left in this period.
    OUT_OF_TIMEYour time allowance is used up.No time is left in this period.
    NO_MORE_SESSIONSomeone else is using this account. Try again in a few minutes.The member is at the plan's limit of simultaneous devices.
    UNSUPPORTED_AUTH_METHODThis network only supports PAP login.The router sent CHAP. Set login-by=http-pap.

    After login

    The status page shows "Hi, USERNAME", the time online, the time left and the data left when the router fills them in, a Continue link to the first page the member asked for, and a Log out button. The router decides which of these values it has, so some may be missing on your RouterOS version.
