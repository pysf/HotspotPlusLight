    HotspotPlus Lite documentation

    HotspotPlus Lite keeps Wi-Fi accounts for a MikroTik hotspot on your own network. This page explains what it is and how to start.

    What it is

    HotspotPlus Lite manages Wi-Fi accounts for one MikroTik hotspot router. You make plans (data limit, time limit, validity period, speed limit, simultaneous devices) and members, or you print a batch of vouchers. At every login, the router asks the server and the server says yes or no. While the member is online, the server counts the usage and can disconnect the member.

    • One program, one SQLite file. No cloud and no database server.
    • An admin panel in your browser for members, plans, vouchers, live sessions and usage.
    • A built-in RADIUS server for the router, with PAP login. RADIUS is the protocol the router uses to ask the server about each login.
    • Ready-made login pages for the router, in 8 designs.

    How the parts fit

    1. The router runs the hotspot and stores the login page. It sends each login and each accounting packet (usage updates during a session) to the server by RADIUS.
    2. HotspotPlus Lite runs on a computer on the same network. It answers RADIUS on UDP 1812 and UDP 1813 and serves the admin panel on TCP 8081. It keeps everything in one SQLite file.
    3. You use the admin panel in a browser. Members see only the login page on the router.

    How it works explains each step. The README has diagrams (on GitHub).

    What you need

    • A MikroTik router with the hotspot feature already working.
    • A computer on the same network as the router that is always on. It can run Linux, Windows or macOS (x86 or ARM).
    • UDP 1812 and UDP 1813 open from the router to that computer, and UDP 3799 open from that computer to the router. See Router setup.
    Local network only

    The admin panel uses plain HTTP and has no HTTPS. Run it on your local network and do not make it reachable from the hotspot network or the internet.

    What it does not do

    • One router and one admin account. No multi-tenant mode (one install for many businesses).
    • MikroTik routers only, and PAP login only. If the router uses CHAP, the server rejects the login.
    • No payments and no SMS. Members cannot sign up or choose a plan by themselves.
    • The admin panel and all messages are in English. You can translate the login page by hand.
    • No HTTPS and no reverse proxy setup. The server is made for a local network.

    Where to start

    1. Install the program and start it once (see Installation).
    2. Set it up as a service (see Run as a service).
    3. Log in, set a new password and create a plan and a member (see First login).
    4. Set up the router (see Router setup) and upload a login page (see Hotspot login pages).

    Keep Backup and upgrade and Troubleshooting close at hand.

    Where it comes from

    HotspotPlus Lite is a rewrite of HotspotPlus. It keeps the rules for members, plans and limits. It removes the extra infrastructure and the multi-tenant product around them. It is open source under the AGPL-3.0. The code is on GitHub.
