    HotspotPlus Lite documentation

    HotspotPlus Lite keeps Wi-Fi accounts for a MikroTik hotspot on your own network. This is a short guide to what it is and how to start.

    What it is

    HotspotPlus Lite manages Wi-Fi accounts for one MikroTik hotspot router. You make plans (data, time, validity, speed, number of devices) and members, or you print a batch of vouchers. At every login the router asks the program, and the program says yes or no. While the member is online it counts the usage, and it can disconnect the member.

    • One program, one SQLite file. No cloud and no database server.
    • A web admin panel for members, plans, vouchers, live sessions and usage.
    • A built-in RADIUS server (PAP login) for the router.
    • Ready-made login pages for the router, in 8 designs.

    How the parts fit

    1. The router runs the hotspot and stores the login page. It sends each login and each accounting packet to the server by RADIUS.
    2. HotspotPlus Lite runs on a computer on the same network. It answers RADIUS on UDP 1812 and 1813, serves the admin panel on TCP 8081, and keeps everything in one SQLite file.
    3. You use the admin panel in a browser. Members only ever see the login page on the router.

    The page How it works explains each step. The README has diagrams (on GitHub).

    What you need

    • A MikroTik router with the Hotspot feature already working.
    • A computer that is always on, on the same network as the router: Linux, Windows or macOS (x86 or ARM).
    • UDP 1812 and 1813 open from the router to that computer, and UDP 3799 open from that computer to the router. See Router setup.
    Local network only

    The admin panel uses plain HTTP and has no HTTPS. Run it on your local network and do not make it reachable from the hotspot network or the internet.

    What it does not do

    • One router and one admin account. No multi-tenant mode.
    • MikroTik routers only, and PAP login only. If the router uses CHAP, the server rejects the login.
    • No payments, SMS, self-signup or plan choice by members.
    • The admin panel and all messages are in English. You can translate the login page by hand.
    • No HTTPS and no reverse proxy setup: it is made for a local network.

    Where to start

    1. Install the program and start it once.
    2. Make it run as a service.
    3. Log in, set a password, and create a plan and a member.
    4. Follow the router setup and upload a login page.

    Keep backup and upgrade and troubleshooting close.

    Where it comes from

    HotspotPlus Lite is a rewrite of HotspotPlus. It keeps the member, plan and quota rules and removes the infrastructure and the multi-tenant product around them. It is open source under the AGPL-3.0, and the code is on GitHub.
