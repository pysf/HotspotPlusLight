    Configuration

    Every environment variable of the server with its default, the env file format, the commands and the settings on the Settings page.

    Environment variables

    These variables control how the server starts. Some of them are used only at the first start, to fill in the first values. After that, you change them only on the Settings page, and the variable is ignored. If a variable is set but differs from the saved setting, the server writes a warning with both values to its log at start. You make all other settings on the Settings page.

    VariableDefaultMeaning
    HSP_SECRET_KEY(auto-generated)The secret key: base64 of 32 random bytes. The server uses it as the AES-GCM key for the stored member passwords. At the first start, the server creates the key and saves it to hsp.key in the data folder. The server never creates a key when hsp.db already exists. If the key is missing then, the server does not start: restore hsp.key from your backup or set HSP_SECRET_KEY. Set this variable only if you want to manage the key yourself. If it is set to a key that does not fit the database, the server does not start.
    HSP_DATA_DIRdataThe data folder that holds hsp.db and hsp.key. The server creates it if it is missing.
    HSP_ADMIN_ADDR:8080The admin panel address. Used only at the first start, to fill in the Settings page. After that, the variable is ignored: change the value on the Settings page (restart required).
    HSP_RADIUS_AUTH_ADDR:1812The RADIUS login address. Used only at the first start, to fill in the Settings page. After that, the variable is ignored: change the value on the Settings page (restart required).
    HSP_RADIUS_ACCT_ADDR:1813The RADIUS accounting address. Used only at the first start, to fill in the Settings page. After that, the variable is ignored: change the value on the Settings page (restart required).
    HSP_ADMIN_USERNAMEadminThe admin user name. Used only at the first start, when the server creates the account. After that, change it on the Password and username page: the variable is ignored.
    HSP_RADIUS_SHARED_SECRET(generated)The RADIUS shared secret. Used only at the first start. It must have only letters and digits. If the value is not valid, the server does not start. If it is empty, the server creates a shared secret of 24 letters and digits. Later, change it on the Settings page.
    HSP_LOG_LEVELinfoThe log level: debug, info, warn or error. Used only at the first start, to fill in the Settings page. After that, the variable is ignored: change the value on the Settings page (restart required).
    HSP_LOG_FORMATtextThe log format (text or json). Used only at the first start, to fill in the Settings page. After that, the variable is ignored: change the value on the Settings page (restart required).
    HSP_UPDATE_API_URLhttps://api.github.comThe address of the GitHub API for the update check. For tests and mirrors only. Leave it empty.
    HSP_DEV(empty)Set to 1 to show the component gallery at /admin/dev/components. This is for developers. Leave it off.

    To listen on one address only, give that address. For example, set HSP_ADMIN_ADDR=192.168.1.10:8080 at the first start, or change it later on the Settings page. Use this to keep the admin panel off the hotspot network.

    A wrong value stops the start

    If HSP_LOG_LEVEL, HSP_LOG_FORMAT or HSP_SECRET_KEY (when set) is not valid, the server stops with an error that names the variable.

    A bad saved address can stop the start

    The 3 addresses must use different ports. If the server cannot use a saved address, it stops at start and the admin panel is down. To reset the 3 addresses, stop the server and run sqlite3 data/hsp.db "UPDATE settings SET admin_addr=':8080', radius_auth_addr=':1812', radius_acct_addr=':1813';". Then start the server again.

    The env file

    Instead of setting environment variables, you can put them in an env file and start the server with --env-file. This option works for serve and for admin set-password:

    # hsp.env
HSP_DATA_DIR=/var/lib/hotspotpluslight
HSP_LOG_LEVEL=info   # a space and a hash start a comment
    hotspotpluslight --env-file hsp.env serve
    • One KEY=VALUE per line. Empty lines and lines that start with # are skipped.
    • Spaces around keys and values are removed. You can put a value in one pair of single or double quotes.
    • In an unquoted value, a space followed by # starts a comment. A # with no space before it is kept.
    • A real environment variable that is not empty wins over the same key in the file.

    Commands

    CommandWhat it does
    hotspotpluslight serveStarts the server: the admin panel and both RADIUS listeners.
    hotspotpluslight gen-keyPrints a new key (base64 of 32 random bytes). The server creates the key automatically at the first start. Use this command only if you want to set HSP_SECRET_KEY yourself, before the first start. A new key cannot read an existing database.
    hotspotpluslight admin set-password [--stdin]Sets a new admin password and ends every open admin session. On a terminal, it asks twice and does not show what you type. With --stdin, or when the input is not a terminal, it reads one line. It uses the same rules as the Password page.
    hotspotpluslight service install [--dir FOLDER]Windows and Linux only: registers the service (run as Administrator, or with sudo on Linux). See Run as a service.
    hotspotpluslight service start | stop | uninstallWindows and Linux only: starts, stops or removes the service.
    hotspotpluslight versionPrints the version. A build from source prints dev.
    --env-file FILEReads the settings from FILE, for serve and admin set-password.

    If you build from source, make set-password runs admin set-password for the database in ./data.

    The Settings page

    These settings are saved in the database. You change them on the Settings page of the admin panel. The page has groups: Business, RADIUS, Members, Voucher defaults, Server addresses and Logs. One Save settings button at the bottom saves all of them. Next to the RADIUS shared secret, the Generate button makes a new random secret of 24 letters and digits. Settings marked restart required take effect at the next server start. After you save one, the page shows a notice until you restart the server yourself. The listen addresses and log settings come from the environment variables only at the first start. After that, only this page changes them.

    SettingDefaultMeaning
    Business name(empty)Your business name. It is printed at the top of every voucher. It is also shown in the top bar of the admin panel and in the browser tab. Leave it empty to hide it.
    Time zoneUTCChoose it from the list (UTC and the common zones of every region). Dates are shown in this time zone. Daily usage and voucher expiry also follow it. Set it first.
    RADIUS shared secret(generated)Letters and digits only, no spaces or symbols. Use a long random value of 20 or more characters. It must match the shared secret on the router. A change applies at once.
    Disconnect (CoA) port3799The router port that gets Disconnect requests.
    Accounting interval (seconds)60How often the router sends usage updates. At least 10.
    Default plan(none)Preselected on the new member form.
    Voucher username prefixwifiEnglish letters and digits only.
    Next voucher number1360The number in the user name of the next voucher.
    Maximum vouchers per batch30The largest batch you can make.
    Voucher password length6From 4 to 20 digits.
    Voucher help text(a default English text)Printed on every voucher.
    Keep finished sessions (days)90Finished sessions older than this are removed. 0 keeps them forever.
    Check for updatesOnThe server asks GitHub once a day if a newer version exists. It sends only its version number. Off means it never contacts GitHub. A change applies at once. The Updates page shows the result and has a Check now button. A development build never checks.
    Admin address (restart required):8080Address and port of the admin panel (TCP) and /healthz. To listen on one address only, give that address, for example 192.168.1.10:8080.
    RADIUS auth address (restart required):1812Address and port for RADIUS login requests (UDP).
    RADIUS acct address (restart required):1813Address and port for RADIUS accounting (UDP).
    Log level (restart required)infodebug, info, warn or error.
    Log format (restart required)texttext (key=value lines) or json. Logs go to stderr.
