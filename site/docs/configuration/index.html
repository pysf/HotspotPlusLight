    Configuration

    Every environment variable of the server with its default, the env file format, the commands, and the Settings page.

    Environment variables

    The server reads these variables when it starts. Everything else is on the Settings page.

    VariableDefaultMeaning
    HSP_SECRET_KEY(required)Base64 of 32 random bytes. It is the AES-GCM key for the stored member passwords. The server will not start without it, or with a key that does not fit the database. Make one with hotspotpluslight gen-key.
    HSP_DATA_DIRdataThe folder that holds hsp.db. It is created if it is missing.
    HSP_ADMIN_ADDR:8081Address and port of the admin panel (TCP) and /healthz.
    HSP_RADIUS_AUTH_ADDR:1812Address and port for RADIUS login requests (UDP).
    HSP_RADIUS_ACCT_ADDR:1813Address and port for RADIUS accounting (UDP).
    HSP_ADMIN_USERNAMEadminThe admin user name. It is used only at the first start, when the account is created.
    HSP_RADIUS_SHARED_SECRET(generated)The RADIUS shared secret. It is used only at the first start. If it is empty, a secret is generated. Later, change it on the Settings page.
    HSP_LOG_LEVELinfodebug, info, warn or error.
    HSP_LOG_FORMATtexttext (key=value lines) or json. Logs go to stderr.
    HSP_DEV(empty)Set to 1 to show the component gallery at /admin/dev/components. It is for developers; leave it off.

    To listen on one address only, give the address, for example HSP_ADMIN_ADDR=192.168.1.10:8081. Use this to keep the admin panel off the hotspot network.

    A wrong value stops the start

    An invalid HSP_LOG_LEVEL, HSP_LOG_FORMAT or HSP_SECRET_KEY makes the server exit with an error that names the variable.

    The env file

    Instead of setting variables, put them in a file and start with --env-file. The option works for serve and for admin set-password:

    # hsp.env
HSP_SECRET_KEY=your-key-here
HSP_DATA_DIR=/var/lib/hotspotpluslight
HSP_LOG_LEVEL=info   # a space and a hash start a comment
    hotspotpluslight --env-file hsp.env serve
    • One KEY=VALUE per line. Empty lines and lines that start with # are skipped.
    • Keys and values are trimmed. A value can be in one pair of single or double quotes.
    • In an unquoted value, a space followed by # starts a comment. A # with no space before it is kept.
    • A real environment variable that is not empty wins over the file.

    Commands

    CommandWhat it does
    hotspotpluslight serveStarts the server: the admin panel and both RADIUS listeners.
    hotspotpluslight gen-keyPrints a new HSP_SECRET_KEY (base64 of 32 random bytes). It needs no database.
    hotspotpluslight admin set-password [--stdin]Sets a new admin password and ends every open admin session. It asks twice without echo on a terminal. With --stdin, or when input is not a terminal, it reads one line. It uses the same rules as the password page.
    hotspotpluslight service install [--dir FOLDER]Windows only: registers the service. See Running as a service.
    hotspotpluslight service start | stop | uninstallWindows only: starts, stops or removes the service.
    hotspotpluslight versionPrints the version. A build from source prints dev.
    --env-file FILEReads the settings from FILE, for serve and admin set-password.

    With the source code, make set-password runs admin set-password for the ./data database.

    The Settings page

    These are saved in the database and edited on the Settings page of the admin panel. They apply without a restart.

    SettingDefaultMeaning
    Business name(empty)Your business name. It is printed at the top of every voucher and shown in the admin header and the browser tab. Leave it empty to hide it.
    Time zoneUTCAn IANA name such as Europe/London. Dates are shown in this zone, and daily usage and voucher expiry follow it. Set it first.
    RADIUS shared secret(generated)It must match the secret on the router. A change applies at once.
    Disconnect (CoA) port3799The router port that gets Disconnect requests.
    Accounting interval (seconds)60How often the router sends usage updates. At least 10.
    Default plan(none)Preselected on the new member form.
    Voucher username prefixwifiEnglish letters and digits.
    Next voucher number1360The number of the next voucher user name.
    Maximum vouchers per batch30The largest batch you can make.
    Voucher password length6From 4 to 20 digits.
    Voucher help text(a default English text)Printed on every voucher.
    Keep finished sessions (days)90Older finished sessions are removed. 0 keeps them forever.
