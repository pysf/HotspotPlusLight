    First login

    Log in as admin, set a new password, then create a plan, a member and a batch of vouchers.

    Log in

    Open http://SERVER-IP:8081/admin. After you set your password, the admin panel opens on the Dashboard. At the first start, the user name is admin and the password is admin. You can set another user name with HSP_ADMIN_USERNAME before the first start, or change it later on the Password and username page. The first-start block that the server prints says the same.

    Change the password at once. Until you do, anyone who can reach TCP 8081 can log in as admin.

    Set a new password

    After you log in, the server sends you to the password page. No other page opens until you set a new password. The page also has a Username field that shows the current name. Keep admin or type your own: 4 to 32 letters, numbers, dots or dashes. The server saves the new name and the new password together. The rules for the password are:

    • At least 10 characters, and at most 72 bytes.
    • Not your user name (the new one, if you changed it), not admin, and not a very common password.
    • There are no other rules, so a long phrase is fine. The Generate button makes a random password.

    You can change the password later with the Password link in the top bar. The page is called Password and username and has one card for each. The Username card asks for your current password and then saves the new name. From then on, log in with the new name: the old name stops working. When you change the user name or the password, your other admin sessions end and this one stays open. An admin session ends after 1 hour without activity.

    If you forget it

    Reset it on the command line of the server. The command asks for the new password twice and does not show what you type. It uses the same rules as the page and ends every open admin session. It does not change the user name:

    hotspotpluslight admin set-password

    If you build from source, make set-password does the same for the database in ./data. If your settings are in an env file, add --env-file. To run the command as the service user, see Run as a service.

    If you forgot the user name, read it from the database: sqlite3 data/hsp.db "SELECT username FROM admin;".

    Create a plan

    After the first start there are no plans, and every member needs a plan. Open the Plans page and choose Add plan. A side panel opens:

    FieldMeaning
    NameShown in lists. Each name must be unique (case does not matter).
    Valid for (days)A whole number, at least 1. The member can use the plan this long, counted from when the member is created.
    Speed limit0 means no limit. The same speed applies to download and upload.
    Data limit0 means unlimited data. Download and upload count together.
    Time limit (minutes)0 means unlimited time.
    Devices at the same timeHow many sessions the member can have at once. At least 1.
    Renew automatically when the validity endsAt the next login after the validity period ends, the usage is reset and a new period starts.

    When you edit a plan, the change applies to every member on that plan at their next login. Each plan is a card that shows its member count and its limits, with Edit and Delete buttons. You cannot delete a plan that members or batches use, or the default plan. Its Delete button is dimmed and the card says why. On the Settings page, you can pick a default plan. The new member form then selects it for you.

    Create a member

    Open the Members page and choose Add member. A side panel opens with a user name, a password and a plan. Under the plan, a short line shows what the plan gives: data, days, speed and devices. The Generate button puts a random 6-digit password in the field. A user name can have only English letters and digits (up to 64), and case does not matter. If you leave the user name empty, the server uses the mobile number. If you leave the password empty, the server makes a random 6-digit number. The rarely used fields are in More options: Valid until, name, mobile, email, national code, MAC address and the Account enabled switch. After you save, the panel shows the user name and the password, each with a Copy button, and a Print login details button for the voucher.

    To change a member, click the user name or choose Edit in the row menu. The panel starts with the current state: the status, whether the member is online, the data used, the Account enabled switch, Kick now (it works only while the member is online) and Print login details. Below that are the user name (you can change it only while the member is offline), the password (hidden; choose New for a new 6-digit password), the plan and Valid until. Choose Save changes to store them. More options holds the personal fields, Renew, Open details (the full member page, with extra data and the usage summary) and Delete.

    • Extra data adds to the plan's data limit for the current period. A renewal resets it.
    • Renew starts a new period now: usage and extra data go back to zero.
    • Disable also disconnects the member's open sessions.
    • The row menu (the three dots) has Edit, Renew, Disable, Disconnect and Delete. Tick rows to delete many members at once. A bar shows how many are selected.
    • Valid until is optional. After that time, the member cannot log in.

    Print vouchers

    Open the Vouchers page. The form is on the left and the list of batches is on the right. Choose a plan, the number of vouchers and an optional batch name. The number can be up to the maximum set on the Settings page (30 by default). Each voucher is a member. Its user name is the prefix plus a number (for example wifi1360). Its password is random digits (6 by default).

    The vouchers print 18 per A4 page, 3 across and 6 down, with a help text. You can use the print button on a row of the batch list at any time. The Used column shows how many vouchers of the batch were used. A batch can also have its own Valid for (days). The vouchers then expire at midnight after that many days plus one. The server uses the time zone from the Settings page.

    The period starts when the voucher is created

    It does not start at the first login. A voucher printed long before it is used may already be near the end of its validity period.

    See who is online

    The Dashboard shows how many members are online now, today's traffic and the Router link card. The Online now page lists the open sessions (user name, name, IP and MAC address, time online, data down and up) and refreshes every 10 seconds. The Kick button asks first and then sends a Disconnect request to the router. This is a RADIUS message (RADIUS is the protocol the router uses to ask the server about each login). The Usage page has a switch for 7, 30 or 90 days. It shows the total traffic, the daily average, the busiest day, a chart with one bar per day and the top 10 members.
