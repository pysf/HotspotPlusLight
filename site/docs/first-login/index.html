    First login

    Log in as admin, set a new password, then create a plan, a member and a batch of vouchers.

    Log in

    Open http://SERVER-IP:8081/admin. Once your password is set, the admin panel opens on the Dashboard. On the first start the account is admin with the password admin (you can change the user name with HSP_ADMIN_USERNAME before the first start). The first-start block printed by the server says the same.

    Do this at once: until the password is changed, anyone who can reach port 8081 can log in as admin.

    Set a new password

    After you log in you are sent to the password page. No other page opens until you set a new password. The rules:

    • At least 10 characters, and at most 72 bytes.
    • Not your user name, not admin, and not a very common password.
    • No other rules, so a long phrase is fine. The Generate button makes a random one.

    You can change it later on the Password page (link in the top bar). Your other admin sessions end and this one stays. An admin session ends after one hour without activity.

    If you forget it

    Reset it from the command line of the server. It asks twice without echo, uses the same rules as the page, and ends every open admin session:

    hotspotpluslight admin set-password

    With the source code, make set-password does the same for the ./data database. Use --env-file if your settings are in a file, and see Running as a service for the service user.

    Create a plan

    No plan exists after the first start, and every member needs a plan. Open Plans and choose Add plan. A side panel opens:

    FieldMeaning
    NameShown in lists. Names are unique, ignoring case.
    Valid for (days)A whole number, at least 1. The member can use the plan this long, counted from when the member is created.
    Speed limit0 means no limit. One speed is used for download and upload.
    Data limit0 means unlimited data. Counts download and upload together.
    Time limit (minutes)0 means unlimited time.
    Devices at the same timeHow many sessions the member can have at once. At least 1.
    Renew automatically when the validity endsAt the next login after the validity ends, the usage is reset and a new period starts.

    Editing a plan changes it for every member on it, at their next login. Each plan is a card with its member count and its limits, and Edit and Delete buttons. A plan that members or batches use, or the default plan, cannot be deleted: its Delete button is dimmed and the card says why. On Settings you can pick a default plan that the new member form preselects.

    Create a member

    Open Members and choose Add member. A side panel opens with a user name, a password and a plan. Under the plan, a short line shows what it gives: data, days, speed and devices. The Generate button puts a random 6-digit password in the field. A user name has English letters and digits only (up to 64) and is not case-sensitive; if you leave it empty, the mobile number is used. If you leave the password empty, a random 6-digit number is made. The rarely used fields (Valid until, name, mobile, email, national code, MAC address and the Account enabled switch) are in More options. After you save, the panel shows the user name and password with a Copy button for each, and a Print login details button for the voucher.

    To change a member, choose Edit in the row menu. The panel starts with the current state: the status, whether the member is online, the data used, the Account enabled switch, Kick now (it works only while the member is online) and Print login details. Below are the user name (you can change it only while the member is offline), the password (hidden; choose New for a new 6-digit one), the plan and Valid until. Choose Save changes to store them. More options holds the personal fields, Renew, Open details (the full member page, with extra data and the usage summary) and Delete.

    • Extra data adds to the plan's data limit for the current period. It is reset by a renewal.
    • Renew starts a new period now: usage and extra data go back to zero.
    • Disabling a member also disconnects the member's open sessions.
    • The row menu (the three dots) has Edit, Renew, Disable, Disconnect and Delete. Tick rows to delete many members at once. A bar shows how many are selected.
    • Valid until is optional. After that moment, logins are refused.

    Print vouchers

    Open Vouchers. The form is on the left and the list of batches is on the right. Choose a plan, how many vouchers (up to the maximum in Settings, 30 by default), and an optional batch name. Each voucher is a member with a user name made from the prefix and a number (for example wifi1360) and a random password of digits (6 by default).

    The vouchers print 18 per A4 page, 3 across and 6 down, with a help text. Use the print button on a row of the batch list at any time to print the sheet again. The Used column shows how many vouchers of the batch were used. A batch can also have its own Valid for (days): the vouchers then expire at midnight after that many days plus one, in the Settings time zone.

    The period starts when the voucher is created

    Not at the first login. A voucher printed long before it is used may already be near the end of its plan period.

    See who is online

    The Dashboard shows how many are online now, today's traffic and the router link. The Online now page lists the open sessions (user name, name, IP and MAC address, time online, data down and up) and refreshes every 10 seconds. Kick asks first, then sends a RADIUS Disconnect request to the router. The Usage page has a switch for 7, 30 or 90 days. It shows the total traffic, the daily average, the busiest day, a chart with one bar per day and the top 10 members.
