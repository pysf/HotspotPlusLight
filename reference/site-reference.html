Introduction

NetAccounting is a small, self-hosted service for managing internet users: create accounts, assign plans with volume, duration, speed and device limits, and watch usage. It is built for hotels, cafes and small ISPs that hand out Wi-Fi accounts to guests.

It ships as one Go binary with an embedded SQLite database. There is no database server to install and nothing else to keep running.

RequirementsA Linux server (x86-64 or ARM64) with a public or LAN address. That is all.

Installation

Download the latest release for your platform, unpack it and make it executable.

curl -LO \
  https://github.com/OWNER/REPO/releases/latest/download/netaccounting_linux_amd64.tar.gz
tar -xzf netaccounting_linux_amd64.tar.gz
sudo install -m 755 netaccounting /usr/local/bin/

Check that it runs:

netaccounting version

Build from source

git clone https://github.com/OWNER/REPO.git
cd REPO
go build -o netaccounting ./cmd/server

Run as a service

Create a dedicated user and a systemd unit so the service starts on boot and restarts on failure.

sudo useradd --system --home /var/lib/netaccounting --create-home netacct
# /etc/systemd/system/netaccounting.service
[Unit]
Description=NetAccounting
After=network-online.target

[Service]
User=netacct
ExecStart=/usr/local/bin/netaccounting serve
WorkingDirectory=/var/lib/netaccounting
Restart=always

[Install]
WantedBy=multi-user.target
sudo systemctl daemon-reload
sudo systemctl enable --now netaccounting

Put it behind a reverse proxy such as Caddy to get HTTPS automatically:

accounting.example.com {
    reverse_proxy 127.0.0.1:8080
}

Configuration

Settings come from environment variables or flags. Defaults work for a first try.

SettingDefaultDescription
LISTEN_ADDR:8080Address and port to listen on.
DB_PATH./data/app.dbLocation of the SQLite database file.
BASE_URLhttp://localhost:8080Public URL, used for links and cookies.
SESSION_TTL24hHow long an admin stays signed in.

First login

Open the address in your browser and sign in with the admin account created on first start. Then:

  1. Create a plan. Go to Internet plans and add one, for example 20 GB, 30 days, 10 Mbps, 2 devices.
  2. Create a user. Go to Users, choose New user, pick the plan and press create.
  3. Share the details. Use Copy details and send the username and password to your guest.

Hotspot login page

Guests see a simple page when they connect to your Wi-Fi. You can change its heading, subtitle, logo and color theme from the admin settings.

Available themes: air, midnight, aurora, dusk, ripple, sunrise and ocean.

TipUse a square logo on a transparent background. It is shown at 56×56 pixels.

Backup & upgrade

All data lives in one SQLite file, so a backup is a copy. Use SQLite's own command so the copy is consistent while the service is running:

sqlite3 /var/lib/netaccounting/data/app.db ".backup '/backups/app-$(date +%F).db'"

To upgrade, replace the binary and restart. Database migrations run automatically on start.

sudo systemctl stop netaccounting
sudo install -m 755 netaccounting /usr/local/bin/
sudo systemctl start netaccounting
